# 01. 게임 컨셉

## 1. 핵심 철학 [확정]

> **"수많은 무공을 수집하되, 하나의 초식을 만 번 갈고닦아 누구도 따라올 수 없는 경지에 도달한다."**

일초만련은 캐릭터 레벨만 올리는 일반적인 RPG가 아니다. 다양한 문파의 무공과 비급을 수집하고, 각 무공에 속한 초식을 **독립적으로** 수련하며, 자신이 선택한 무공을 극한까지 성장시키는 것이 핵심이다.

## 2. 차별점 [확정]

- **무공마다 독립적인 초식 수련 기록**을 가진다. 주력 무공을 바꿔도 이전 무공의 수련 기록과 해금 상태는 영구 보존된다.
- 초식 하나를 **10,000회** 수련하면 **대성**에 이르고, 수련 진행도에 따라 공격 연출이 7단계로 눈에 띄게 변한다. 플레이어는 "만 번 갈고닦은 초식"을 화면으로 확인한다.
- 수집(넓이)과 만련(깊이)이 두 개의 성장 축이다. 수집은 선택지를 늘리고, 만련은 그 선택을 완성한다.

## 3. 장르와 플레이 감각

- 2D 픽셀 무협 RPG, 세로형 화면, 싱글 플레이, 서버 없음.
- **자동 전투가 기본**이며, 플레이어는 **연속초식 버튼**(토글)으로 "현재 초식 집중 수련"과 "해금한 초식 전부로 공략"을 오간다. 수동 기술 버튼은 없다.
- 템포는 **초식당 대성까지 수 시간** 수준의 중간 템포이며, 오프라인 수련(효율 50%, 최대 8시간)으로 일상적인 접속 패턴을 지원한다.

## 4. 핵심 게임 루프

### 4-1. 짧은 루프 (분 단위)

```
몬스터 접근 → 자동 공격 / 자동 초식 발동 → 수련 횟수 증가
          ↘ 공략이 필요하면 연속초식 켜기 ↗
일반 몬스터 50마리 처치 → 보스 등장 → 보스 처치 → 다음 스테이지
```

### 4-2. 중간 루프 (시간~일 단위)

```
초식 수련 → 대성(10,000회) → 다음 초식 해금 → 전투력 상승 → 더 높은 스테이지
던전 도전 → 비급 조각 / 강화석 / 은냥 획득 → 무공 개방, 장비 강화
```

### 4-3. 긴 루프 (주~월 단위)

```
여러 무공 수집 → 무공별 초식 대성 누적 → 경지 승급(레벨 + 대성 초식 수)
문파 수집, 특정 초식 대성 업적 → 추가 보상
새 지역 개방 → 새 무공/몬스터/장비
```

## 5. 대상 플레이어

- 방치형/자동 전투 RPG를 즐기되, 단순한 숫자 성장보다 **눈에 보이는 숙련의 변화**를 원하는 플레이어.
- 무협 장르(문파, 비급, 초식, 경지)에 익숙하거나 관심 있는 한국어 사용자.
- 짧게 자주 접속하는 모바일 사용자. 오프라인 수련으로 접속하지 않는 시간에도 성장이 이어진다.

## 6. 수익화 방향 [확정]

무료 + 광고 + 소액 인앱 결제(편의 중심). **확률형 뽑기 결제는 하지 않는다.** MVP에는 결제를 넣지 않고 구조만 열어 둔다. 자세한 내용은 [08-economy.md](08-economy.md).
