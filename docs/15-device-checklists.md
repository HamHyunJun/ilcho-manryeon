# 15. 기기 확인 체크리스트

각 단계의 디버그 APK를 기기에 설치한 뒤 눈으로 확인할 항목이다. 자동 테스트(헤드리스)로 확인한 항목은 따로 적었다.
디버그 도구는 [육성] 화면 아래쪽에 있다(시간 배속, 수련 횟수 편집, 무공 모두 개방, 저장 확인).

## M5. 연속초식 버튼

1. 전투 아래쪽에 "수련 중: 매화검법 1초식 · 입문 · n / 10,000"과 진행 막대가 보인다.
2. [연속초식 OFF] 버튼을 누르면 금색으로 강조되며 "연속초식 ON"으로 바뀌고, 아래에 "1초식" 순서가 표시된다.
3. [육성]에서 1, 2초식을 "9999"로 만든 뒤 잠시 기다려 대성시키면, 연속초식 ON 상태에서 1 → 2 → 3초식 이름이 차례로 캐릭터 머리 위에 뜬다.
4. 다시 눌러 OFF로 바꾸면 수련 중인 초식(3초식) 이름만 반복해서 뜬다.
5. 하단 앱바 [장비] [소환] [던전] [육성]이 보이고, [육성]은 육성 화면을 열고 닫는다. 아직 없는 메뉴는 화면 가운데에 "MVP 이후 추가 예정" 안내가 뜬다.
6. 연속초식을 켠 채 앱을 껐다 켜면 켜진 상태가 유지된다.

자동 테스트: 연속초식 중 해금 초식 모두 수련, 끄면 수련 중인 초식만 반복, 버튼 상태 전환.
