# 08. 재화 경제 시스템

## 1. 재화 5종 [확정]

| 재화 | 성격 | 주요 수급처 [가안] | 주요 소비처 [가안] |
|---|---|---|---|
| 은냥 | 기본 재화 | 몬스터 처치, 재화 던전, 일일 미션 | 장비 강화, 기타 기본 비용 |
| 영약 | 수련/승급 재화 | 일일 미션, 업적, 보스 | 수련 가속, 경지 승급(채택 시) |
| 소환패 | 소환 재화 | 일일 미션, 업적, 보스 | 확률 소환 |
| 강화석 | 장비 재료 | 장비 던전, 장비 분해 | 장비 강화 |
| 금원보 | 광고/유료 재화 | 소액 결제, 보상형 광고, 업적 | 편의 상품 |

- 재화 용도 배정(재화 던전 → 은냥, 장비 던전 → 강화석, 소액 결제는 금원보로 일원화)은 기획 보완 단계의 기본안이며, 세부 수급량과 비용은 [가안]이다.

## 2. 재화가 아닌 아이템 [확정]

| 아이템 | 용도 |
|---|---|
| 비급 조각 (무공별) | 필요 개수를 모으면 무공 개방 |
| 소환 조각 (소환체별) | 중복 소환 시 전환, 모으면 해당 소환체 확정 획득 |

재화 수를 늘리지 않기 위해 조각은 "인벤토리 아이템"으로 따로 관리한다.

## 3. 재화 흐름도

```
[일반 스테이지] ──몬스터 처치──> 은냥, 경험치, 장비(드롭)
[보스]          ──────────────> 비급 조각(후보), 영약, 소환패
[비급 던전]     ──────────────> 비급 조각 ──> 무공 개방
[장비 던전]     ──────────────> 장비, 강화석 ──> 장비 강화
[재화 던전]     ──────────────> 은냥(요일제 검토)
[장비 분해]     ──────────────> 강화석
[일일 미션/업적] ─────────────> 영약, 은냥, 소환패, 금원보
[소환패]        ──확률 소환──> 소환체 / 중복 시 소환 조각
[영약]          ──────────────> 수련 가속, 승급
[금원보]        ──────────────> 편의 상품
```

## 4. 수익화 [확정]

### 4-1. 원칙

- **무료 + 광고 + 소액 인앱 결제**.
- 결제는 **편의 중심**: 수련 가속권, 광고 제거, 편의 기능 등.
- **확률형 뽑기 결제는 하지 않는다.**
- **MVP에는 결제와 광고를 넣지 않고 구조만 열어 둔다.** 상점 데이터와 금원보 재화 필드를 미리 정의해, 나중에 결제 SDK를 붙여도 저장 구조를 바꾸지 않게 한다.

### 4-2. 광고 [확정: 보상형 중심 방향]

보상형 광고(시청하면 보상)를 중심으로 쓴다. 적용 위치 후보(모두 [미확정] O-34, O-35):

- 수련 가속 일정 시간
- 오프라인 보상 추가 지급
- 금원보 소량 지급
- 던전 추가 입장

### 4-3. 인앱 결제 상품 후보 [미확정] O-37

- 광고 제거
- 수련 가속권
- 금원보 패키지
- 편의 기능(예: 장비 보관함 확장)

> 주의: 금원보로 소환패를 살 수 있으면 사실상 확률형 결제가 된다. 이 경로를 열지 말지는 O-30에서 결정한다.

## 5. 경제 설계 원칙

- [제안] 핵심 성장(초식 수련)은 **결제로 건너뛸 수 없고 가속만 가능**하게 한다. 편의 중심 결제 원칙과 만련 철학을 지키기 위한 해석이다. 장점은 철학 보호와 공정성, 단점은 결제 매력 감소, 개발 난이도는 낮다.
- 모든 수급량, 비용, 확률은 데이터 값으로 둔다.
- 재화 인플레이션을 막기 위해 은냥 소비처를 충분히 둔다. 소비처가 부족하면 육성 메뉴(O-20)에서 보완을 검토한다.
