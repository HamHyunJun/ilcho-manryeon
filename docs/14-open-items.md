# 14. 미확정 항목

이 문서는 아직 결정하지 않은 항목을 모은 것이다. 본문 문서에서는 이 항목들을 임의로 결정하지 않았다. 구현 중 자리 값이 필요한 경우에는 데이터 파일에 테스트용 값을 넣고, 결정되면 데이터만 바꾼다.

**우선순위**
- **A**: 해당 MVP 단계 착수 전에 결정이 필요함
- **B**: MVP 중 임시 처리로 진행 가능, MVP 완성 전 결정
- **C**: MVP 이후 결정
