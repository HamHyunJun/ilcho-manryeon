# 07. 던전 및 콘텐츠

## 1. 일반 스테이지 [확정]

```
일반 몬스터 50마리 처치 → 보스 등장 → 보스 처치 → 다음 스테이지
```

각 지역은 여러 스테이지로 구성한다.

## 3. 던전 [확정]

### 3-1. 우선 구현 3종

| 던전 | 주요 보상 | 상태 |
|---|---|---|
| 비급 던전 | 비급 조각 | **MVP 포함** (M9) |
| 장비 던전 | 장비, 강화석 | 구현 (가안 수치, 3-3) |
| 재화 던전 | 은냥 (그 외 재화 후보) | 구현 (가안 수치, 요일제 구조 포함, 3-3) |

- 재화 던전은 **요일제**(요일마다 보상 재화가 다름)를 검토한다.
- 보스 던전과 무한 도전은 **후속**으로 둔다.

> [미확정] 던전 입장 제한(일일 입장 횟수, 입장권 등), 난이도 단계, 클리어 조건(제한 시간 / 처치 수), 요일제 적용 여부와 요일별 보상 배정, 소탕(자동 클리어) 기능 여부. → O-31

### 3-2. 던전 공통 구조 [가안]

던전은 일반 스테이지와 같은 전투 시스템을 쓰고, 데이터로 다음을 다르게 정의한다.

- 몬스터 구성과 웨이브
- 클리어 조건
- 보상 테이블
- 입장 조건

던전에서도 초식이 정상 발동하면 **수련 횟수가 오른다.** (확정 사항 2의 규칙을 그대로 적용. 던전에서만 배율을 다르게 할지는 데이터로 가능하나 값은 정하지 않는다.)

### 3-3. 던전 3종 구현 가안 [가안]

O-31이 미확정이라 아래 내용은 모두 구현 가안이며, 수치는 data/dungeons/*.json에서 바꾼다.

| 항목 | 비급 던전 (manual_cave) | 장비 던전 (equipment_vault) | 재화 던전 (silver_valley) |
|---|---|---|---|
| 클리어 조건 | 웨이브 3개 처치, 180초 | 웨이브 3개 처치(마지막 보스), 180초 | 60초 동안 처치, 최소 10마리 (`time_attack`) |
| 하루 입장 | 3회 | 2회 | 2회 |
| 난이도 1 / 2 / 3 입장 | 스테이지 1 / 4 / 8 돌파 | 스테이지 3 / 6 / 9 돌파 | 스테이지 2 / 5 / 8 돌파 |
| 난이도 적 배율 | ×1.0 / ×1.5 / ×2.2 | ×1.2 / ×1.7 / ×2.4 | ×1.0 / ×1.6 / ×2.3 |
| 보상 (난이도 1) | 조각 2회 × 2~4개, 은냥 200 | 강화석 4~6, 장비 1개(고급 이상), 은냥 100 | 은냥 300 + 처치당 25 |
| 보상 (난이도 3) | 조각 4회 × 3~5개, 은냥 700 | 강화석 11~15, 장비 2개(희귀 이상), 은냥 350 | 은냥 1,000 + 처치당 90 |

- **난이도 단계**: 던전마다 3단계(초급/중급/상급). 난이도별 스테이지 조건을 채우고, 2단계부터는 바로 아래 난이도를 한 번 클리어해야 열린다. 난이도는 적 배율(`scaling`)과 보상 덮어쓰기(`rewards`)로 정의한다.
- **장비 던전 장비**: 등급은 일반 드롭과 같은 가중치로 뽑되 최소 등급(`min_grade`) 아래면 끌어올린다. 기본 능력치에는 난이도 적 배율을 스테이지 배율처럼 곱한다. 보관함이 가득 차면 일반 드롭과 같이 버리고 안내한다(O-27 가안).
- **재화 던전 요일제**: 요일표(`weekday`, 일~토 7칸)로 요일마다 지급 재화와 배율을 정할 수 있다. 지금은 재화가 은냥·강화석뿐이라 은냥만 주고 토·일 1.5배로 둔다. 영약·소환패 등이 생기면 요일표만 바꾸면 된다.
- **소탕**: 한 번 클리어한 난이도는 전투 없이 바로 클리어할 수 있다. 입장 1회를 쓰고, 재화 던전은 그 난이도의 최고 처치 수로 보상을 계산한다.
- 입장 횟수는 입장(또는 소탕) 때 차감하고 실패해도 돌려주지 않는다(M9 가안 유지). 던전 몬스터는 경험치·은냥만 주고 장비를 떨어뜨리지 않으며, 스테이지 처치 수에 들어가지 않는다.

## 4. 오프라인 보상 [확정]

- 앱을 꺼 둔 동안에도 **수련이 효율 50%로 진행**된다.
- 최대 **8시간**까지 인정한다.
- 효율과 최대 시간은 **데이터 값**이다.
- 계산 방식: 접속 종료 시점의 주력 무공, 해금 상태, 발동 모드(단일 수련 / 연속초식)를 기준으로, 온라인에서 같은 시간 동안 정상 발동했을 횟수를 추정하고 효율을 곱한다. [가안]

```
오프라인 수련 횟수 = 추정 정상 발동 횟수(경과 시간) × 수련 배율 × 오프라인 효율(0.5)
경과 시간 = min(실제 경과 시간, 최대 인정 시간(8시간))
```

- 오프라인 중 초식이 대성에 도달하면 다음 초식을 해금하고, 남은 시간은 다음 초식에 이어서 반영한다. [가안]
- **시계 조작 완화**: 서버가 없으므로 완전히 막을 수 없다. 저장 시 기기 시간과 함께 단조 시간(부팅 후 경과 시간)을 기록하고, 기기 시간이 뒤로 갔거나 비정상적으로 앞섰을 때 보상을 제한한다. 재부팅으로 단조 시간 비교가 불가능하면 최대 인정 시간 이하로만 지급한다. ([10-save-data.md](10-save-data.md))

- 오프라인 수련은 종료 시점에 연속초식을 켜 두었더라도 **항상 단일 수련 모드 기준**(수련 중인 초식 1개 반복)으로 계산한다(확정 사항 23).
> [미확정] 오프라인 중 재화/경험치/스테이지 진행도 지급 여부. 확정된 것은 수련 진행뿐이다. → O-32
> [미확정] 오프라인 추정 발동 횟수 계산 기준(초당 발동 수 고정값 / 현재 스테이지 기준 시뮬레이션). → O-33
> [미확정] 광고 시청으로 오프라인 보상 추가 지급 여부. → O-34

## 5. 수련 가속 수단 [확정: 존재 / 미확정: 방식]

수련 템포가 수 시간이므로 수련 가속 수단을 둔다(확정 사항 1). 가속은 **수련 배율을 곱하는 효과**로 구현해 기존 수련 규칙과 일관되게 한다.

후보 (모두 [미확정] O-35):

- 영약 소모: 일정 시간 수련 배율 증가
- 보상형 광고 시청: 일정 시간 수련 배율 증가
- 소액 결제 편의 상품(수련 가속권)

## 6. 퀘스트와 업적 [확정 기본안]

| 종류 | 내용 | 보상 |
|---|---|---|
| 일일 미션 | 몬스터 처치, 던전 도전, 초식 발동 횟수 등 매일 초기화 | 소량의 영약, 은냥 |
| 성장 업적 | 첫 대성, 문파 수집, 경지 승급, 스테이지 도달 등 | 단계별 보상 |
| 숨겨진 퀘스트 | 특정 조건 달성 시 발견 | 비급 획득 경로로 연결 |

- 미션과 업적은 **데이터 기반**으로 정의한다.
- 일일 초기화 시각은 기기 로컬 시간 기준. [가안: 오전 5시]

> [미확정] 미션/업적 목록과 보상 수치. → O-36

## 7. 튜토리얼 [확정 기본안]

별도 튜토리얼 맵 없이 **첫 스테이지 안에서** 짧게 안내한다.

1. 자동 전투 안내 (몬스터 접근, 자동 공격)
2. 연속초식 버튼 안내 (단일 수련과 연속초식 전환)
3. 무공 장착 안내
4. 첫 초식 수련 진행 안내 (수련 횟수, 수련 단계 표시)

- 단계별 진행 여부는 저장 데이터에 기록해 다시 띄우지 않는다.
