# 05. 캐릭터 성장 시스템

## 1. 성장 요소 [확정]

| 요소 | 설명 |
|---|---|
| 캐릭터 레벨 | 몬스터 처치 경험치로 상승. 경지 승급 조건의 한 축 |
| 체력 | 0이 되면 쓰러짐 |
| 공격력 | 피해 계산의 기본값 |
| 방어력 | 받는 피해 감소 |
| 치명타 | 치명타 확률과 피해 배율 |
| 회피 | 공격을 피할 확률 |
| 내공 | 초식 발동 자원 |
| 무공 숙련도 | 무공별·초식별 수련 기록 (03 문서) |
| 캐릭터 경지 | 9단계 장기 성장 목표 |

능력치 상승 경로: 레벨업, 경지 승급, 장비, 보조 무공 패시브, 소환(동료 패시브).

> [미확정] 레벨업 시 능력치 자동 상승 외에 "육성" 메뉴에서 은냥으로 능력치를 직접 올리는 시스템을 둘지. 하단 메뉴 "육성"의 세부 구성이 원문에 정의되어 있지 않다. → O-20
> [미확정] 레벨 상한과 경험치 곡선. → O-21

## 2. 전투력

상단 HUD에 표시하는 종합 지표다. 능력치, 장비, 무공(대성 초식 수 등)을 가중합한 값으로 계산한다. 계산식은 [가안]이며 밸런스 단계에서 확정한다.

## 3. 경지 [확정]

```
삼류 무인 → 이류 무인 → 일류 무인 → 절정 고수 → 초절정 고수 → 화경 → 현경 → 생사경 → 무극
```

### 3-1. 승급 조건 [확정]

**캐릭터 레벨 + 대성한 초식 수**를 함께 요구한다.

- "대성한 초식 수"는 **모든 무공의 대성 초식을 합산**한다. 특정 무공을 강제하지 않는다.
- 레벨 조건으로 진행 속도를 보장하고, 대성 조건으로 만련 철학을 성장에 반영한다.

### 3-2. 경지별 조건 표 [가안]

아래 수치는 구조 설명용 가안이다. 실제 값은 수련 템포 테스트 후 확정한다.

| 단계 | 경지 | 필요 레벨 [가안] | 필요 대성 초식 수 [가안] |
|---|---|---|---|
| 1 | 삼류 무인 | 시작 | 0 |
| 2 | 이류 무인 | 10 | 1 |
| 3 | 일류 무인 | 20 | 3 |
| 4 | 절정 고수 | 35 | 6 |
| 5 | 초절정 고수 | 50 | 10 |
| 6 | 화경 | 70 | 15 |
| 7 | 현경 | 90 | 21 |
| 8 | 생사경 | 110 | 28 |
| 9 | 무극 | 130 | 36 |

> [미확정] 경지별 능력치 상승량, 승급 시 재화 소모 여부(영약 등), 승급 연출. → O-22
> [미확정] 경지에 따른 해금 요소(자동 슬롯 확장, 지역 개방 등). 자동 슬롯 확장은 "경지 등" 후속으로만 정해 두었다. → O-23

## 4. 충돌 점검

- 경지 승급에 대성 초식 수가 필요하므로 **수련 템포가 곧 경지 진행 속도**가 된다. 경지 조건 수치는 [11-balance.md](11-balance.md)의 수련 템포 계산과 함께 조정해야 한다.
- 대성 초식 수를 무공 합산으로 세기 때문에, 여러 무공의 낮은 초식만 대성시키는 플레이(1초식 위주 수집)가 효율적일 수 있다. 뒤 초식일수록 강하게 만들어 깊은 수련에도 보상이 있도록 밸런스로 보완한다. [제안: 장점은 수집과 만련 양쪽에 동기 부여, 단점은 초식별 수치 설계 부담, 난이도 낮음(데이터 조정만 필요)]
