# 13. MVP 로드맵

## 1. MVP 범위 [확정]

| 포함 | 내용 |
|---|---|
| 지역 | 청풍산 1지역 |
| 무공 | 매화검법(검법), 나한권(권법), 음양오행술(술법) |
| 시스템 | 전투, 수련, 저장, 장비 기본 |
| 던전 | 비급 던전 1종 |

기본안으로 함께 들어가는 것: 오프라인 수련(확정 사항 7), 저장 내보내기/가져오기(확정 사항 16), 첫 스테이지 튜토리얼과 설정(확정 사항 17).

| MVP 제외 (후속) | 비고 |
|---|---|
| 소환 (동료/영물/수호령) | 구현 순서 제안은 [06-equipment-summon.md](06-equipment-summon.md) |
| 장비 던전, 재화 던전 | MVP 이후 1순위 콘텐츠 |
| 보스 던전, 무한 도전 | 후속 |
| 장비 세트 효과, 분해 | 확정 범위지만 "장비 기본"을 넘어서므로 MVP 이후 [가안] |
| 광고, 인앱 결제 | 구조만 열어 둠 |
| 클라우드 저장 | 출시 전 재검토 |
| 일일 미션/업적 | MVP 이후 [가안] |

> 장비 분해/세트, 일일 미션/업적을 MVP에 넣을지는 "장비 기본"의 해석에 따라 달라진다. 이 문서는 MVP 이후로 [가안] 배치했다. → [미확정] O-41

## 2. 진행 원칙 [확정]

- 기능을 한꺼번에 구현하지 않고 **작동하는 단위**로 하나씩 완성한다.
- 각 단계는 "완료 기준"을 실제 기기(또는 에디터)에서 확인한 뒤 다음 단계로 넘어간다.
- 각 단계는 PR 단위로 올리고 승인 후 합친다.

## 3. 단계별 계획

### M0. 프로젝트 기반

- Godot 4 프로젝트 생성, 세로 해상도/화면비 설정, 폴더 구조([12-tech-structure.md](12-tech-structure.md)).
- Autoload 뼈대: `DataRegistry`, `GameState`, `EventBus`, `SaveManager`, `TimeService`.
- Android 테스트 빌드 1회 성공.

**완료 기준**: 빈 화면이 Android 기기에서 세로로 실행된다. JSON 데이터 하나를 읽어 화면에 출력할 수 있다.

### M1. 전투 코어

- 왼쪽 고정 캐릭터, 오른쪽에서 몬스터 생성/접근(임시 스프라이트).
- 사거리 판정, 기본 공격 자동 발동, 피해 계산, 피해 숫자, 몬스터 체력 표시, 처치.
- 몬스터 공격, 캐릭터 체력.

**완료 기준**: 몬스터가 계속 생성되고 캐릭터가 자동으로 공격해 처치한다. 몬스터도 캐릭터를 공격한다.

**M1 구현 메모**: 수치는 모두 가안(data/balance/combat.json, data/monsters/monsters.json). 피해 = 공격력 × 계수 × (1+보너스) × 치명타 배율 × 100/(100+방어력), 최소 1. 쓰러짐은 임시 처리(O-06), 몬스터는 임시 2종(O-10). 무공 초식 발동은 M3에서 붙인다.

### M2. 스테이지 루프

- 처치 수 집계, 50마리 처치 후 보스 등장, 보스 처치 후 다음 스테이지.
- 보스 공격 예고 + 2개 패턴(임시).
- 상단 HUD: 지역명, 스테이지, 처치 진행도, 보스까지 남은 수.
- 청풍산 스테이지 데이터(JSON).

**완료 기준**: 스테이지 1 → 보스 → 스테이지 2로 자동 진행되고 HUD가 맞게 바뀐다. 캐릭터가 쓰러졌을 때의 처리는 O-06 결정 전까지 임시 처리(스테이지 재시작)로 둔다.

**M2 구현 메모**: 청풍산 10스테이지(가안, O-10), 스테이지 배율 x1.08, 임시 보스 1종(내려찍기, 지면 충격파). 성장 요소가 아직 없어 기본 능력치로는 스테이지 2까지 돌파하고 3에서 막힌다(가안 수치 기준). 이 벽은 이후 장비·수련·소환으로 넘는 구조와 맞다. 체력 회복 방식은 O-51. 수치 조정: 캐릭터 공격력 40, 생성 간격 2.5초, 동시 3마리, 임시 몬스터 공격력 하향(모두 가안).

### M3. 무공과 초식 수련 (핵심)

- 무공 데이터 3종 로드, 주력 1 + 보조 2 장착(보조는 패시브만).
- 단일 수련 모드: 수련 중인 주력 초식 1개 반복 발동, 재사용 대기, 내공.
- 연속초식 모드: 1초식부터 해금 초식 순서대로 발동(버튼 UI는 M5, 여기서는 디버그 토글).
- 수련 중인 초식 자동 지정(가장 앞 미대성 초식).
- 정상 발동 시에만 수련 횟수 증가, 배율과 소수점 누적.
- 10,000회 대성 → 다음 초식 해금.
- **무공 교체 시 수련 기록 보존**.
- 육성 메뉴의 최소 화면: 무공 장착, 초식별 수련 횟수 표시.
- 디버그 도구: 수련 횟수 편집, 시간 배속.

**완료 기준**: 원문 4-2의 예시 시나리오(매화검법 수련 → 나한권으로 교체 → 다시 매화검법으로 복귀 시 기록 복원)가 그대로 재현된다. 보조로 장착한 무공은 초식이 발동하지 않고 패시브만 적용된다. 대상이 없을 때 수련 횟수가 오르지 않는다.

**M3 구현 메모**: 시작 무공 매화검법(#29), 발동하면 빗나가도 1회(#28). 다른 무공은 비급 획득(M9) 전까지 디버그 "무공 모두 개방"으로 연다. 보조 패시브는 무공별 고정값(가안, O-09). 같은 무공의 주력·보조 동시 장착 불가(가안). 대성 후에도 횟수를 계속 센다(가안, O-12). 초식이 더해져 화력이 늘어 캐릭터 공격력을 20으로 낮췄다(가안). 이 수치로는 스테이지 3까지 돌파하고 4에서 막힌다.

### M4. 저장과 불러오기

- 저장 스키마 v1([10-save-data.md](10-save-data.md)), 이중 저장, 해시 검증.
- 저장 시점: 주요 이벤트, 주기, 백그라운드 전환.
- 마이그레이션 뼈대(v1 → v2 테스트용).
- 자동 테스트: 저장/불러오기 왕복, 파일 하나가 깨졌을 때 복구.

**완료 기준**: 앱을 강제 종료하고 다시 켜도 무공별/초식별 진행도, 장착 정보, 스테이지가 복원된다. 저장 파일 하나를 일부러 깨도 다른 파일로 복구된다.

**M4 구현 메모**: 해시만으로 깨진 파일을 거르고 암호화는 하지 않는다(가안, O-38). 강제 종료 시 마지막 저장 이후 최대 30초분의 진행을 잃을 수 있다. 마이그레이션은 버전별 변환 함수를 쌓는 뼈대만 두었고, 실제 v2 변환은 저장 구조가 바뀌는 단계에서 추가한다. 내보내기/가져오기는 M11(O-38).

### M5. 연속초식 버튼

- 연속초식 토글 버튼 UI, 켜짐 상태 강조 표시.
- 수련 중인 초식(가장 앞 미대성 초식)과 진행도 표시.
- 연속초식 중 정상 발동한 모든 초식의 수련 횟수 반영.

**완료 기준**: 버튼으로 단일 수련과 연속초식을 오갈 수 있고, 연속초식 중에는 해금한 초식이 순서대로 발동하며 각 초식의 수련 횟수가 오른다. 끄면 수련 중인 초식만 다시 반복한다.

**M5 구현 메모**: 전투 아래 조작 영역에 수련 중인 초식, 진행 막대, 큰 연속초식 토글을 두고, 하단 앱바(장비/소환/던전/육성)를 붙였다. 육성 화면은 앱바 메뉴로 옮겼다. 소환은 MVP 범위 밖(확정 사항 18)이라 "MVP 이후" 안내만 띄운다. 연속초식 켜짐 상태는 저장된다. 임시 UI(기본 테마)다.

### M6. 수련 단계 이펙트

- `EffectDirector`, 계열 3종(검법/권법/술법) × 7단계 프리셋(파티클/셰이더 파라미터).
- 단계 상승, 대성 달성 알림 연출.

**완료 기준**: 디버그 도구로 수련 횟수를 바꾸면 이펙트가 7단계로 눈에 띄게 달라지고, 세 계열의 이펙트가 서로 구별된다. 모바일 기기에서 프레임 저하가 허용 범위 안이다.

**M6 구현 메모**: 프리셋은 data/effects/effect_presets.json(계열 색·파티클 모양 + 단계별 파티클 수, 크기, 지속 시간, 충격파, 검기, 먼지, 잔상, 균열, 화면 흔들림). 수치는 모두 가안. 텍스처 없이 코드 드로잉(draw_*)만 쓴다. 셰이더는 아직 쓰지 않았다(Compatibility 렌더러 부담을 줄이려는 판단, 필요하면 대성 연출부터 추가). 대성 전용 연출은 초식 데이터의 `mastery_effect` 칸으로 지정할 수 있게 해 두었고, 지금은 모두 계열 대성 프리셋을 쓴다. 수련 단계는 연출에만 영향을 준다(가안, O-13). 동시 연출 수 상한 6개(가안), 넘치면 오래된 초식 연출부터 지우고 대성 알림은 남긴다. 헤드리스 기준 최대 단계 연출 갱신은 프레임당 0.2ms 안팎. 실제 기기 프레임은 기기 확인 항목(O-40 기준 기기 미정).

### M7. 캐릭터 성장과 경지

- 경험치, 레벨업, 능력치, 전투력 표시.
- 경지 9단계 데이터, 승급 조건(레벨 + 대성 초식 수 합산) 판정과 승급.

**완료 기준**: 레벨과 대성 초식 수 조건을 채우면 경지가 오르고 HUD에 반영된다.

**M7 구현 메모**: 수치는 data/balance/growth.json(모두 가안). 필요 경험치 100 × 레벨^1.6, 레벨당 공격력·체력 +3% 복리, 레벨 상한 150(가안, O-21). 몬스터 경험치에 스테이지 배율을 곱한다(가안). 경지 9단계와 승급 조건은 05 문서 가안 표 그대로이며, 조건을 채우면 자동 승급한다(가안, O-22). 경지 보너스는 공격력·체력·방어력 +10%(이류)부터 +200%(무극)까지 가안. 승급 재화 소모는 없음(가안, O-22). 전투력 = 공격력×10 + 체력 + 방어력×5 + 치명 기대값×1000 + 대성 초식×100(가안). 시뮬레이션(가안 수치): 4시간에 Lv 14, 스테이지 7 돌파, 첫 초식 대성 직전. 이 시점까지 쓰러짐 없이 느리게 진행되므로 M8 장비와 M11 밸런스 조정에서 다시 본다.

### M8. 장비 기본

- 5부위 장착, 6등급, 스테이지 드롭 [가안], 보관함.
- 강화(강화석 + 은냥 [가안]), 기본 옵션과 무공 시너지 옵션 적용.
- 장비 메뉴 화면.

**완료 기준**: 드롭한 장비를 장착/강화하면 능력치와 전투력이 바뀌고, 매화검법 시너지 옵션이 매화검법 초식 피해에만 적용된다.

**M8 구현 메모**: 수치는 data/equipment/equipment.json(모두 가안). 장신구 1칸(O-24). 등급 배율 1.0~4.0(11 문서 가안), 추가 옵션 수는 06 문서 가안 표. 드롭: 일반 몬스터 5%, 보스 100%, 강화석은 일반 5%로 1개·보스 3개(MVP에 분해·장비 던전이 없어 임시 수급처, 가안). 기본 능력치에 스테이지 배율을 곱한다. 강화는 최대 +15, 항상 성공, 단계당 기본 능력치 +5%, 비용 강화석 1+단계·은냥 50+50×단계(O-25 가안). 보관함 100칸, 가득 차면 새 장비를 버리고 안내(O-27 가안). 분해·세트는 넣지 않았다(O-41, 로드맵대로 MVP 이후). 대신 장비 "버리기"만 있다. 무공 시너지 옵션은 대상(전체/계열/무공/초식)이 맞는 초식 피해에만 더한다. 보스 피해, 피해 감소 옵션도 적용된다. 은냥은 몬스터 보상에 스테이지 배율을 곱해 지급한다.

### M9. 비급 조각과 비급 던전

- 비급 조각 아이템, 필요 개수 달성 시 무공 개방.
- 비급 던전 1종(던전 공통 구조 + 보상 테이블), 천장 장치 자리(수치는 테스트용).
- 무공 도감 화면.

**완료 기준**: 비급 던전을 클리어해 조각을 모으고 새 무공을 개방해 장착/수련할 수 있다.

**M9 구현 메모**: 던전 데이터는 data/dungeons/manual_cave.json(웨이브 3개, 마지막 보스, 제한 시간 180초, 하루 3회, 스테이지 1 돌파 후 입장, 모두 테스트용 가안). 던전은 일반 전투를 그대로 쓰며 스테이지 처치 수는 건드리지 않는다. 던전 몬스터는 경험치와 은냥만 주고 장비는 떨어뜨리지 않는다(가안). 보상은 클리어 시 2회 × 조각 2~4개(나한권, 음양오행술 같은 가중치, O-18 가안) + 은냥 200. 필요 조각은 무공당 30개(테스트 수치, O-15). 천장 자리: 클리어 5회마다 개방에 가장 가까운 무공 조각 10개 추가(테스트 수치). 이미 개방한 무공 조각은 조각당 은냥 50으로 바꾼다(O-16 가안). 입장 횟수는 입장할 때 차감하고 실패해도 돌려주지 않는다(O-31 가안). 무공 도감은 던전 화면과 육성 화면에서 연다. 디버그 "무공 모두 개방"과 도감의 "조각 +10"은 테스트용으로 남겼다(정식 빌드에서 디버그 묶음과 함께 숨길 예정).

### M10. 오프라인 수련

- `TimeService`의 기기 시간/단조 시간 기록, 시계 조작 완화 규칙.
- 오프라인 수련 계산(항상 단일 수련 기준, 효율 50%, 최대 8시간), 대성 시 다음 초식으로 이월.
- 복귀 요약 화면.

**완료 기준**: 앱을 끄고 일정 시간 뒤 켜면 경과 시간에 맞는 수련 결과가 반영되고 요약이 나온다. 기기 시간을 뒤로 돌리거나 크게 앞당겨도 상한 이상 보상이 나오지 않는다.

**M10 구현 메모**: OfflineTraining(scripts/offline). 같은 실행 안(모바일 백그라운드 → 복귀)은 단조 시간 차이, 앱을 다시 켜면 기기 시간 차이를 쓴다. 실행마다 세션 ID(TimeService)를 새로 만들어 구분한다. 기기 부팅 여부는 Godot에서 직접 알 수 없어 "실행이 바뀌면 기기 시간 + 8시간 상한"으로 처리한다. 기기 시간이 저장 시점보다 과거면 보상 0, 그 시점을 지나기 전까지 계속 0, 지난 뒤에는 원래 저장 시점부터 센다(data["offline"].rollback_until_unix). 초당 발동 수는 초식 간격·대기시간·내공 회복 중 가장 느린 값(가안 O-33, 현재 1회/초). 오프라인 중 경험치·재화·스테이지 진행은 주지 않는다(가안 O-32). 60초 미만은 요약 없이 무시(가안). 데스크톱 창 포커스 아웃은 게임이 계속 돌아 오프라인으로 치지 않는다.

### M11. 마무리 (MVP 완성)

- 저장 내보내기/가져오기.
- 설정 화면(사운드, 진동, 자동 초식, 저장, 한국어).
- 첫 스테이지 튜토리얼 4단계.
- 사운드 임시 적용, 밸런스 1차 조정, Android 릴리스 빌드.

**완료 기준**: 새로 설치한 기기에서 튜토리얼부터 청풍산 진행, 무공 3종 수련/교체, 장비, 비급 던전, 오프라인 수련, 저장 이전까지 한 흐름으로 플레이할 수 있다.

**M11 구현 메모**:
- 저장 내보내기/가져오기는 텍스트 코드("ILCHO1:" + Base64, 해시 검사, 암호화 없음, O-38 가안). 클립보드로 복사·붙여 넣기 하며, 가져오기 전에 요약을 보여 주고 덮기 전 진행은 백업 슬롯에 남긴다.
- 설정은 화면 위 [설정] 버튼으로 연다: 효과음·배경음 음량, 진동, 화면 흔들림, 언어(한국어 고정). 자동 초식 on/off는 O-47 해결 내용대로 넣지 않았다.
- 튜토리얼은 첫 화면 안내 상자 4단계(data/balance/tutorial.json, 문구·조건 가안). 조건을 채우거나 [확인]을 누르면 넘어가며, 끝낸 단계는 저장한다.
- 사운드는 O-01 미정이라 코드로 만든 임시 효과음만 넣었다(외부 음원 없음). 배경음은 없다.
- 디버그 도구는 디버그 빌드에서만 보인다(OS.is_debug_build).
- 밸런스 1차: 스테이지 배율 1.08 → 1.10(11 문서 범위 상한), 장비 기본 능력치와 일반 몬스터 드롭률(5% → 2%) 하향. 시뮬레이션(가안 수치, 장비 자동 장착·강화): 스테이지 하나에 약 3.5~4분(11 문서 목표 3~5분), 청풍산 10스테이지를 약 45분에 돌파, 4시간에 Lv 18. 이후는 마지막 스테이지 반복(O-10). 온라인 초식 발동 비율이 약 55%로 측정되어 오프라인 계산에 반영했다(online_uptime, O-33).
- Android: 디버그 APK와 함께 서명하지 않은 릴리스 APK를 CI에서 만든다. 서명 키와 비밀값은 저장소·워크플로에 넣지 않았다. 패키지 이름은 임시 값(O-50) 그대로다. 버전 0.2.0(코드 2).

## 4. MVP 이후 순서 [제안]

| 순서 | 내용 | 이유 |
|---|---|---|
| 1 | 장비 분해 + 세트 효과, 장비 던전 | 확정된 장비 범위 완성, 강화석 수급처 확보 |

이 순서는 승인 전 제안이다.

**던전 완성 구현 메모** (MVP 이후 1·2순위 중 던전 부분): 장비 던전(equipment_vault), 재화 던전(silver_valley, 요일제 구조), 던전 3종 공통 난이도 3단계와 소탕을 넣었다. 규칙은 scripts/dungeon/DungeonRules.gd(난이도 합치기, 종류별 보상, 요일, 검증), 진행은 DungeonRun(웨이브 / 시간 제한 처치 두 가지 클리어 조건), 기록은 ManualCollection의 collection.dungeons에 그대로 둔다. 던전 화면은 던전마다 카드(난이도 선택, 클리어 조건, 보상 안내, 남은 입장, 입장·소탕)와 최근 결과를 보여 준다. 수치는 모두 가안(07 문서 3-3, O-31). 장비 분해·세트, 일일 미션은 이번 범위가 아니다.
