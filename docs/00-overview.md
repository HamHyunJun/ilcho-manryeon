## 5. 개발 진행 원칙 [확정]

1. 확정되지 않은 시스템을 임의로 최종 결정하지 않는다.
2. 확정된 기획을 임의로 변경하지 않는다.
3. 새로운 기능을 제안할 때는 장점, 단점, 개발 난이도를 함께 설명한다.
4. 기존 시스템과 충돌하거나 중복되는 기능은 먼저 알린다.
5. 무공 수집과 초식 만련이라는 핵심 철학을 훼손하지 않는다.
6. 향후 확장성을 고려하되, 불필요하게 복잡한 설계는 피한다.
7. 기획과 개발을 분리하고, 승인 전에는 대규모 구현에 들어가지 않는다.
8. 개발은 MVP부터 작동하는 단위로 하나씩 완성한다.
