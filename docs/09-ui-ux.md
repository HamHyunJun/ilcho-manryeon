# 09. UI/UX

## 1. 화면 기준 [확정]

- 세로형(Portrait) Android 화면.
- 기준 해상도 [가안]: 논리 해상도 **720 × 1280**(9:16), 픽셀 아트는 정수 배율로 확대. 다양한 화면비(19.5:9 등)는 위/아래 여백을 늘려 대응하고, 안전 영역(노치, 제스처 바)을 고려한다.
- 중앙 전투 영역은 가능한 한 넓게 확보한다.

## 2. 전투 화면 레이아웃 [확정 구성]

```
┌──────────────────────────────┐
│ [상단 영역]                    │
│ 경지 · 전투력 · 보유 재화        │
│ 체력 바 / 내공 바               │
│ 지역명 · 스테이지 번호            │
│ 처치 진행도 (예: 37 / 50)        │
│ 보스까지 남은 몬스터 수           │
├──────────────────────────────┤
│ [중앙 전투 영역]                 │
│                              │
│  캐릭터(좌측 고정)  ← 몬스터 접근   │
│  공격 애니메이션 / 초식 이펙트       │
│  피해량 표시 / 몬스터 체력 표시      │
│  보스 전투 연출                   │
│                              │
├──────────────────────────────┤
│ [전투 조작 영역]                 │
│ 수련 중 초식 표시 · [연속초식]       │
├──────────────────────────────┤
│ [하단 앱바]                     │
│  장비 │ 소환 │ 던전 │ 육성        │
└──────────────────────────────┘
```

### 2-1. 상단 영역 [확정]

캐릭터 경지, 전투력, 보유 재화, 체력 및 내공, 현재 지역명, 스테이지 번호, 몬스터 처치 진행도, 보스 출현까지 남은 몬스터 수.

- 재화 5종을 모두 상단에 상시 노출하면 좁으므로, 주요 재화(예: 은냥, 금원보)만 표시하고 터치 시 전체 재화를 펼치는 방식을 [가안]으로 둔다.

### 2-2. 중앙 영역 [확정]

왼쪽 고정 플레이어 캐릭터, 오른쪽에서 접근하는 몬스터, 공격 애니메이션, 초식별 공격 이펙트, 피해량 표시, 몬스터 체력 표시, 보스 전투 연출.

추가 표시 [가안]:

- 초식 발동 시 초식 이름과 수련 단계 짧게 표시
- 수련 단계 상승, 대성 달성 시 강조 연출과 알림

### 2-3. 전투 조작 영역 [확정]

- 자동 초식 설정: 현재 수련 중인 초식과 진행도 표시
- **연속초식 버튼 (토글)**: 켜면 1초식부터 해금한 초식을 순서대로 발동하고, 끄면 단일 수련으로 돌아간다(확정 사항 19, 22). 켜져 있는 동안 버튼을 강조 표시한다.
- 연속초식을 끄면 아직 대성하지 못한 남은 초식만 반복한다(확정 사항 24). 별도의 자동 초식 on/off 설정은 없다.
- 수동 기술 버튼은 없다(확정 사항 21). 전투 조작 영역이 작아진 만큼 중앙 전투 영역을 넓힌다. [가안]

## 3. 하단 앱바 [확정]

| 메뉴 | 상세 화면 내용 |
|---|---|
| 장비 | 부위별 장착, 보관함, 강화, 분해, 세트 효과 확인 |
| 소환 | 동료/영물/수호령 소환, 보유 목록, 조각 확정 획득 |
| 던전 | 비급/장비/재화 던전 목록과 입장 |
| 육성 | 무공 장착(주력 / 보조는 패시브만), 무공 도감, 초식 수련 현황, 경지 승급, 캐릭터 능력치 |

- 디자인 시안 반영으로 앱바 구성이 상점 │ 육성 │ 메인 │ 던전 │ 소환으로 바뀌었고, 장비는 육성 화면의 [장비] 탭으로 옮겼다 (7장).
- 무공 관련 화면은 "육성" 메뉴에 두는 것을 [가안]으로 한다. 원문은 육성 메뉴의 세부 구성을 정하지 않았다. → [미확정] O-20
- 각 메뉴의 상세 화면에서도 전투는 계속 진행된다(배경 전투 유지). [가안]
- 설정, 우편/알림, 일일 미션, 업적 진입 위치는 상단 보조 버튼으로 두는 것을 [가안]으로 한다.

## 4. 무공 도감 / 수련 현황 화면 [가안 구성]

```
[무공 목록] 문파/계열 필터 · 습득 여부
  └ [무공 상세]
      이름 · 계열 · 문파 · 설명 · 획득 경로
      장착 상태 (주력 / 보조 / 미장착)
      초식 목록
        1초식 ★대성 10,000 / 10,000
        2초식 절정  8,214 / 10,000  [■■■■■■■■□□]
        3초식 잠김
```

## 6. UX 원칙 [가안]

- 한 손 세로 조작: 자주 누르는 버튼은 화면 아래 절반에 둔다.
- 수련 진행이 이 게임의 핵심 보상이므로, 수련 횟수 증가와 단계 상승을 항상 눈에 보이게 한다.
- 복귀 시 오프라인 수련 결과(초식별 증가 횟수, 대성/해금 여부)를 한 화면으로 요약해 보여 준다.
- 픽셀 아트와 어울리는 픽셀 폰트를 쓰되 한글 가독성을 우선한다.

## 7. 디자인 시안 반영 (구현 기준) [가안]

프로젝트에서 합의한 시안(mock-vector-v30-bigbar, mock-grow-screen-v1, design-chibi-hd, design-weapons-v1, design-monster-death-v1, design-skill-effects-v4)을 코드로 반영한 기준이다. 그림은 모두 코드로 그리며 이미지 파일을 쓰지 않는다.

| 항목 | 구현 |
|---|---|
| 상단 바 | 프로필(주인공 얼굴, 경험치 고리, 레벨) · 스테이지(이름, 진행 바, 보스 표시, 진행 문구) · 설정을 같은 가로 중심선(y 92)에 정렬. 위 여백 20px 추가 (`BattleHud.gd`) |
| 캐릭터 | 2등신(큰 머리, 작은 몸통, 각진 형태, 굵은 외곽선, 작은 눈, 큰 무기). 그림 1픽셀 = 화면 1.6px (이전 시안보다 약 25% 작게). 주인공은 공격 준비 자세 (`ChibiArt.gd`) |
| 무공별 복장 | 매화검법 = 검 + 푸른 도복, 나한권 = 철가시 붕대 주먹 + 주황 승복, 음양오행술 = 부적 다발 + 보라 도복. 주력 무공을 바꾸면 바로 바뀐다 |
| 몬스터 | 산적(bandit), 복면 자객(masked), 산채 두목(chief, 1.5배). `monsters.json`의 `sprite`, `sprite_scale` |
| 쓰러짐 | 8프레임: 타격 흰 번쩍 → 밀려남 → 휘청 → 넘어감 → 쾅(먼지) → 반동 → 기절(X눈, 별) → 소멸. 무기가 손에서 빠져 날아간다 (`MonsterDeath.gd`) |
| 초식 이펙트 | 12초식마다 고유 연출(가산 혼합, 구체 음영, 다층 광채, 충격파, 번개, 꽃잎 폭풍, 원근 마법진). 수련 단계가 오르면 커진다. 대상 위 340px 이내로 그려 상단 바를 덮지 않는다 (`TechniqueEffect.gd`) |
| 배경 | 달빛 후광, 별, 안개 낀 5겹 산, 폭포, 누각, 소나무, 매화 가지, 원근 돌바닥, 떨어지는 꽃잎. 정지 부분은 한 번만 그린다 (`BattleBackground.gd`) |
| 하단 앱바 | 높이 134px, 상점 │ 육성 │ 메인(태극, 확대) │ 던전 │ 소환, 아이콘 1.4배, 글자 24. 바로 위에 초식 게이지, 그 위에 연속초식 토글 (`AppBar.gd`, `GameUi.gd`) |
| 육성 화면 | 가운데 큰 주인공과 마법진, 좌우 장비 슬롯 5부위(등급색 테두리, 강화 수치), 능력치 4칸, [장비 / 소환수 / 무공] 탭, 등급 필터가 있는 보유 장비 목록 (`GrowScreen.gd`) |

- 장비는 육성 화면의 [장비] 탭에서 다룬다. 상점과 소환은 MVP 이후 추가 예정이라 누르면 안내만 띄운다.
- 시안의 수치와 장비 이름은 예시이며, 실제 데이터(장비 5부위 무기/투구/갑옷/신발/장신구, 6등급)를 따른다.
- 화면 확인용 스크린샷 도구: `xvfb-run godot --path . -s res://tests/screenshot.gd -- <출력.png> [초] [메뉴] [demo] [무공ID]`
