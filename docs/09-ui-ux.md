# 09. UI/UX

## 1. 화면 기준 [확정]

- 세로형(Portrait) Android 화면.
- 기준 해상도 [가안]: 논리 해상도 **720 × 1280**(9:16), 픽셀 아트는 정수 배율로 확대. 다양한 화면비(19.5:9 등)는 위/아래 여백을 늘려 대응하고, 안전 영역(노치, 제스처 바)을 고려한다.
- 중앙 전투 영역은 가능한 한 넓게 확보한다.

## 2. 전투 화면 레이아웃 [확정 구성]

```
┌──────────────────────────────┐
│ [상단 영역]                    │
│ 경지 · 전투력 · 보유 재화        │
│ 체력 바 / 내공 바               │
│ 지역명 · 스테이지 번호            │
│ 처치 진행도 (예: 37 / 50)        │
│ 보스까지 남은 몬스터 수           │
├──────────────────────────────┤
│ [중앙 전투 영역]                 │
│                              │
│  캐릭터(좌측 고정)  ← 몬스터 접근   │
│  공격 애니메이션 / 초식 이펙트       │
│  피해량 표시 / 몬스터 체력 표시      │
│  보스 전투 연출                   │
│                              │
├──────────────────────────────┤
│ [전투 조작 영역]                 │
│ 자동 초식 설정 (on/off, 순환 표시)  │
│ [필살기] [방어/회복] [자유 초식]     │
├──────────────────────────────┤
│ [하단 앱바]                     │
│  장비 │ 소환 │ 던전 │ 육성        │
└──────────────────────────────┘
```

### 2-1. 상단 영역 [확정]

캐릭터 경지, 전투력, 보유 재화, 체력 및 내공, 현재 지역명, 스테이지 번호, 몬스터 처치 진행도, 보스 출현까지 남은 몬스터 수.

- 재화 5종을 모두 상단에 상시 노출하면 좁으므로, 주요 재화(예: 은냥, 금원보)만 표시하고 터치 시 전체 재화를 펼치는 방식을 [가안]으로 둔다.

### 2-2. 중앙 영역 [확정]

왼쪽 고정 플레이어 캐릭터, 오른쪽에서 접근하는 몬스터, 공격 애니메이션, 초식별 공격 이펙트, 피해량 표시, 몬스터 체력 표시, 보스 전투 연출.

추가 표시 [가안]:

- 초식 발동 시 초식 이름과 수련 단계 짧게 표시
- 수련 단계 상승, 대성 달성 시 강조 연출과 알림

### 2-3. 전투 조작 영역 [확정]

- 자동 초식 설정
- 수동 버튼 3개: 필살기 1, 방어/회복 1, 자유 1 (확정 사항 4)
- 버튼에는 재사용 대기시간 게이지와 내공 부족 상태를 표시한다.
- 버튼 길게 누르기로 슬롯에 넣을 초식을 고르는 방식을 [가안]으로 둔다.

## 3. 하단 앱바 [확정]

| 메뉴 | 상세 화면 내용 |
|---|---|
| 장비 | 부위별 장착, 보관함, 강화, 분해, 세트 효과 확인 |
| 소환 | 동료/영물/수호령 소환, 보유 목록, 조각 확정 획득 |
| 던전 | 비급/장비/재화 던전 목록과 입장 |
| 육성 | 무공 장착(주력/보조), 무공 도감, 초식 수련 현황, 경지 승급, 캐릭터 능력치 |

- 무공 관련 화면은 "육성" 메뉴에 두는 것을 [가안]으로 한다. 원문은 육성 메뉴의 세부 구성을 정하지 않았다. → [미확정] O-20
- 각 메뉴의 상세 화면에서도 전투는 계속 진행된다(배경 전투 유지). [가안]
- 설정, 우편/알림, 일일 미션, 업적 진입 위치는 상단 보조 버튼으로 두는 것을 [가안]으로 한다.

## 4. 무공 도감 / 수련 현황 화면 [가안 구성]

```
[무공 목록] 문파/계열 필터 · 습득 여부
  └ [무공 상세]
      이름 · 계열 · 문파 · 설명 · 획득 경로
      장착 상태 (주력 / 보조 / 미장착)
      초식 목록
        1초식 ★대성 10,000 / 10,000
        2초식 절정  8,214 / 10,000  [■■■■■■■■□□]
        3초식 잠김
```

## 5. 설정 [확정 기본안]

| 항목 | 내용 |
|---|---|
| 사운드 | BGM / 효과음 음량 |
| 진동 | on/off |
| 자동 초식 | on/off |
| 저장 | 내보내기 / 가져오기 |
| 언어 | 한국어만 지원 |

## 6. UX 원칙 [가안]

- 한 손 세로 조작: 자주 누르는 버튼은 화면 아래 절반에 둔다.
- 수련 진행이 이 게임의 핵심 보상이므로, 수련 횟수 증가와 단계 상승을 항상 눈에 보이게 한다.
- 복귀 시 오프라인 수련 결과(초식별 증가 횟수, 대성/해금 여부)를 한 화면으로 요약해 보여 준다.
- 픽셀 아트와 어울리는 픽셀 폰트를 쓰되 한글 가독성을 우선한다.
