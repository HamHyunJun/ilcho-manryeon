# 04. 수집 시스템

## 1. 무공 획득: 비급 조각 [확정]

무공은 **비급 조각을 모아 개방**한다.

```
비급 조각 획득 → 필요 개수 달성 → 무공 개방(1초식 해금) → 초식 수련
```

- 비급 조각은 **무공별 아이템**이다(예: "매화검법 비급 조각"). 재화가 아니다(확정 사항 13).
- 무공마다 개방에 필요한 조각 수를 데이터로 둔다.
- 드롭 운이 나쁜 경우를 보완하는 **천장/확정 보상 장치**를 둔다. 장치의 구조와 수치는 미정이다.

> [미확정] 천장/확정 보상 장치의 구체 방식(예: N회 도전 시 확정 지급, 조각 교환소, 범용 비급 조각 등)과 수치. → O-15
> [미확정] 무공을 이미 개방한 뒤 같은 무공의 비급 조각을 얻었을 때의 처리(다른 재화로 전환, 무공 강화 재료 등). → O-16
> [미확정] 원문 기획의 "비급 해독 또는 습득" 단계를 별도 과정(해독 시간 등)으로 둘지. 이번 결정은 조각 수집 방식이며, 해독 시간 방식은 후속 부가 요소로 검토할 수 있다. → O-17

## 2. 획득 경로 [확정: 원문 예상 경로]

| 경로 | 상태 |
|---|---|
| 비급 던전 | MVP 포함 (확정 사항 12, 18) |
| 보스 처치 | 스테이지 보스 보상 후보 |
| 문파 비경 | 후속 |
| 마교 토벌 | 후속 |
| 고대 유적 탐험 | 후속 |
| 숨겨진 퀘스트 | 후속 (기본안: 숨겨진 퀘스트는 비급 획득 경로로 연결) |
| 무림 상점 | 후속 |
| 무림 대회 | 후속 |

> [미확정] 경로별로 어떤 무공의 조각이 나오는지 배정 규칙. → O-18. 시작 무공은 매화검법으로 확정했다(확정 사항 29).

## 3. 무공 도감 [확정]

도감에 표시할 정보:

- 무공 이름, 무공 계열, 소속 문파, 무공 설명
- 획득 경로
- 습득 여부 (미개방이면 보유 조각 수 / 필요 조각 수)
- 개방된 초식
- 초식별 수련 횟수와 숙련도(수련 단계)
- 대성 여부

## 4. 수집 보상 [원문: 검토 대상]

원문은 "문파별 무공을 모두 수집하거나 특정 초식을 대성했을 때 추가 보상"을 검토 대상으로 둔다. 기본안(확정 사항 17)에서 성장 업적에 "첫 대성, 문파 수집 등"을 넣기로 했으므로, **성장 업적의 보상으로 연결**하는 것까지는 확정이다.

> [미확정] 문파 수집 완료 시 영구 능력치 보너스 등 별도 보상을 줄지. 수집 보상이 너무 강하면 만련의 의미가 줄어든다는 점을 고려해야 한다. → O-19

## 5. 소환 조각과의 관계

소환 조각도 비급 조각과 같은 "조각 → 확정 획득" 규칙을 따른다(확정 사항 10). 두 시스템이 같은 개념을 쓰므로, 조각 UI와 데이터 구조를 공통으로 설계한다. ([06-equipment-summon.md](06-equipment-summon.md))
