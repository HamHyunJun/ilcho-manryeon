# 02. 전투 시스템

## 1. 기본 구조 [확정]

- 캐릭터는 전투 화면 **왼쪽에 고정**된다. 캐릭터가 직접 이동하는 시스템은 없다.
- 몬스터는 화면 **오른쪽에서 생성**되어 캐릭터 방향으로 접근한다.
- 몬스터가 공격 가능한 거리에 들어오면 캐릭터가 **자동 공격**한다.
- **기본 공격과 자동 초식은 자동으로 발동**하고, 플레이어는 별도 버튼으로 **수동 기술**을 발동한다.
- 몬스터 종류에 따라 공격 방식과 특성이 다르다.
- 전투는 자동 진행이 기본이며, 플레이어가 적절한 기술을 직접 사용해 개입할 수 있다.

## 2. 발동 구조

### 2-1. 기본 공격 [확정]

사거리 안에 대상이 있으면 일정 간격으로 자동 발동한다. 기본 공격은 초식이 아니므로 수련 횟수에 포함되지 않는다.

> 기본 공격 간격, 피해 계수는 [가안]이며 [11-balance.md](11-balance.md)에서 관리한다.

### 2-2. 자동 초식 [확정]

- **주력 무공의 해금된 초식을 해금 순서대로 순환 발동**한다. (예: 1초식 → 2초식 → 3초식 → 1초식 …)
- 각 초식은 자기 재사용 대기시간과 내공 소모량을 가진다. 대기 중이거나 내공이 부족한 초식은 순환에서 건너뛴다.
- 설정에서 자동 초식을 끌 수 있다(자동 초식 on/off). 끄면 기본 공격과 수동 기술만 사용한다.
- 자동 슬롯 확장(예: 경지에 따라 순환 규칙이나 슬롯을 늘리는 기능)은 **후속 업데이트**로 둔다.

> [미확정] 보조 무공 초식의 자동 발동 방식. 원문 기획은 "보조 무공 초식도 전투 중 자동 발동"이라고 하고, 확정 사항 4는 "자동은 주력 무공 초식 순환"이라고 한다. 두 규칙이 어떻게 함께 동작하는지(별도 타이머, 순환에 끼워 넣기 등)는 정하지 않았다. → [14-open-items.md](14-open-items.md) O-02

> [미확정] 해금 초식이 많아질수록 순환에서 "수련 중인 초식"의 발동 비중이 줄어든다(1/n). 이를 그대로 둘지, 보정 장치를 둘지 정해야 한다. → O-03

### 2-3. 수동 기술 버튼 [확정]

| 버튼 | 역할 | 비고 |
|---|---|---|
| 필살기 1 | 강력한 공격 초식 | 긴 재사용 대기시간, 큰 내공 소모 [가안] |
| 방어/회복 1 | 피해 감소, 체력 회복 등 | 위기 상황 대응용 |
| 자유 1 | 플레이어가 선택한 초식 | 선택 가능한 범위는 [미확정] O-04 |

- 수동 발동도 **정상 발동하면 수련 횟수에 포함**된다(확정 사항 2).
- 연타로 수련을 우회하는 것은 **재사용 대기시간과 내공 소모**로 막는다.
- 어떤 초식이 필살기/방어/회복 버튼에 들어갈 수 있는지는 초식 데이터의 `slot_type` 값으로 정한다. ([12-tech-structure.md](12-tech-structure.md))

### 2-4. 수련 횟수가 오르는 조건 [확정]

| 상황 | 수련 횟수 |
|---|---|
| 초식이 대상에게 정상적으로 발동함 (자동/수동 모두) | +1 × 수련 배율 |
| 공격 대상이 없어 취소됨 | 증가 없음 |
| 내공 부족, 재사용 대기 등으로 발동하지 않음 | 증가 없음 |
| 기본 공격 | 증가 없음 |

- 수련 배율은 데이터 값이다. 주력 무공 1.0, 보조 무공 0.5(확정 사항 3). 다른 배율(예: 수련 가속 효과)도 같은 구조로 곱한다.
- 배율이 소수일 때 남는 값은 소수점 누적값으로 저장해 손실 없이 합산한다. ([10-save-data.md](10-save-data.md))

> [미확정] "정상 발동"의 정확한 판정 시점(발동 모션 시작 시 / 첫 타격이 적중했을 때 / 회피당한 경우 포함 여부). → O-05

## 3. 내공 [확정 + 가안]

- 체력과 함께 **내공**을 가지며, 초식 발동 시 내공을 소모한다.
- 내공 최대치, 자연 회복량, 초식별 소모량은 [가안]이며 데이터로 관리한다.

## 4. 피해 계산 [가안]

초식 데이터의 공격력 계수, 캐릭터 능력치, 장비/무공 시너지를 조합한다. 아래는 구조 설명용 가안이며 수식과 계수는 밸런스 단계에서 확정한다.

```
최종 피해 = 공격력 × 초식 공격력 계수 × (1 + 피해 증가 합계) × 치명타 배율(발생 시) × 방어 보정
방어 보정 = 100 / (100 + 대상 방어력)    ← [가안]
```

초식별로 관리하는 데이터 [확정]: 공격력 계수, 공격 범위, 공격 대상 수, 내공 소모량, 재사용 대기시간, 공격 속성, 상태이상, 특수 효과, 애니메이션 및 이펙트, 수련 가능 여부.

## 5. 스테이지 루프 [확정]

```
일반 몬스터 50마리 처치 → 보스 등장 → 보스 처치 → 다음 스테이지
```

- 상단 HUD에 몬스터 처치 진행도와 보스 출현까지 남은 몬스터 수를 표시한다.
- 각 지역은 여러 스테이지로 구성한다. 지역당 스테이지 수는 [미확정] O-10.

> [미확정] 캐릭터가 쓰러졌을 때의 처리(스테이지 재시작, 이전 스테이지로 후퇴, 부활 등)와 보스 처치 실패 처리(제한 시간 여부 등). → O-06

## 6. 몬스터 [확정 기본안]

| 유형 | 특징 (기본안) |
|---|---|
| 일반 근접형 | 일정 속도로 접근해 근접 공격 |
| 빠른 돌진형 | 빠르게 접근하거나 돌진 공격, 체력 낮음 |
| 원거리형 | 사거리 밖에서 투사체 공격 |
| 방어형 | 높은 방어력/체력, 느린 이동 |
| 정예 몬스터 | 일반 몬스터 강화형, 추가 보상 |
| 보스 | 50마리 처치 후 등장, 공격 예고 + 2~3개 패턴 |

- 유형별 수치(체력, 공격력, 이동 속도, 사거리)는 [가안]이며 데이터로 관리한다.
- 원거리형은 캐릭터 사거리 밖에서 공격하므로, 캐릭터의 공격 범위/대상 수와 함께 밸런스를 맞춘다.

> [미확정] 정예 몬스터의 등장 규칙(50마리 중 몇 마리, 확률 등)과 원거리형이 캐릭터 사거리 밖에 머무를 때 캐릭터가 공격할 수 있는지. → O-07

## 7. 보스 [확정 기본안]

- 보스는 **공격 예고**(바닥 표시 등)를 한 뒤 공격한다.
- 보스마다 **2~3개의 패턴**으로 시작하고, 보스 전투 연출(등장, 체력바, 패턴 예고)을 넣는다.
- 공격 예고는 수동 버튼(방어/회복, 필살기)을 쓸 타이밍을 알려 주는 역할을 한다. 자동 전투만으로도 클리어 가능하되, 개입하면 더 빠르고 안정적으로 잡을 수 있게 하는 것이 목표다.

## 8. 상태이상과 속성 [확정 데이터 항목]

초식 데이터에 공격 속성과 상태이상을 둔다. 원문 기획의 무공 특성에서 다음 항목이 필요하다.

- 상태이상: 기절, 출혈, 독, 빙결, 화상 등
- 속성: 화염, 빙결, 번개 등 오행 속성
- 특수 효과: 체력 흡수, 반격, 회피, 피해 흡수, 연쇄 공격, 소환 등

> [미확정] 속성 상성표(오행 상생/상극 적용 여부)와 상태이상 수치. → O-08
