# 02. 전투 시스템

## 1. 기본 구조 [확정]

- 캐릭터는 전투 화면 **왼쪽에 고정**된다. 캐릭터가 직접 이동하는 시스템은 없다.
- 몬스터는 화면 **오른쪽에서 생성**되어 캐릭터 방향으로 접근한다.
- 몬스터가 공격 가능한 거리에 들어오면 캐릭터가 **자동 공격**한다.
- **기본 공격과 자동 초식은 자동으로 발동**한다. 수동 기술 버튼은 없고, 플레이어는 **연속초식 버튼**으로 초식 발동 모드를 바꾼다(확정 사항 21).
- 몬스터 종류에 따라 공격 방식과 특성이 다르다.
- 전투는 자동 진행이 기본이며, 플레이어는 상황에 따라 연속초식을 켜고 끄는 방식으로 개입한다.

## 2. 발동 구조

### 2-1. 기본 공격 [확정]

사거리 안에 대상이 있으면 일정 간격으로 자동 발동한다. 기본 공격은 초식이 아니므로 수련 횟수에 포함되지 않는다.

> 기본 공격 간격, 피해 계수는 [가안]이며 [11-balance.md](11-balance.md)에서 관리한다.

### 2-2. 자동 초식과 연속초식 [확정]

자동 초식은 **주력 무공의 초식만** 발동한다. 보조 무공 초식은 발동하지 않는다(확정 사항 20).

자동 초식에는 두 가지 발동 모드가 있다(확정 사항 19).

| 모드 | 동작 | 용도 |
|---|---|---|
| **단일 수련 (기본)** | **현재 수련 중인 초식 1개만 반복 발동**한다. 그 초식이 10,000회 대성하면 다음 초식으로 넘어간다. | 한 초식을 만 번 집중 수련 |
| **연속초식** | '연속초식' 버튼(토글)을 켜면 **1초식부터 지금까지 해금한 초식을 순서대로 발동**한다. 다시 누르면 단일 수련으로 돌아간다. (예: 1초식 → 2초식 → 3초식 → 1초식 …) | 스테이지 공략, 던전 |

- 각 초식은 자기 재사용 대기시간과 내공 소모량을 가진다. 연속초식에서 대기 중이거나 내공이 부족한 초식은 건너뛴다. [가안]
- 별도의 자동 초식 on/off 설정은 없다. **연속초식 버튼을 끄면 아직 대성하지 못한 남은 초식만 반복**한다(확정 사항 24). 예: 2초식까지 10,000회를 채우고 3초식이 열린 상태에서 끄면 3초식만 진행한다.
- 자동 슬롯 확장(경지 등)은 **후속 업데이트**로 둔다.

### 2-3. 연속초식 세부 규칙 [확정]

| 항목 | 규칙 | 출처 |
|---|---|---|
| 버튼 형태 | 토글 (켜고 끄기) | 확정 사항 22 |
| 연속초식 중 수련 | 정상 발동한 **모든 초식**의 수련 횟수가 오른다 | 확정 사항 22 |
| 수련 중인 초식 | **아직 대성하지 못한 가장 앞 초식**을 자동 지정. 대성하면 다음 초식으로 자동으로 넘어간다 | 확정 사항 22 |
| 오프라인 | 항상 단일 수련 모드 기준으로 계산 | 확정 사항 23 |
| 수동 버튼 | 없음. 전투 조작은 연속초식 버튼 하나 | 확정 사항 21 |

- 연속초식 중에도 수련 중인 초식은 그대로 유지되며, 연속초식을 끄면 그 초식을 다시 반복한다.
- 수동 발동이 없으므로 "연타로 수련 우회" 문제는 생기지 않는다.

- 주력 무공의 모든 초식을 대성한 뒤 연속초식을 끄면 **가장 마지막 초식을 반복**한다(확정 사항 26).

> [미확정] 연속초식만의 보너스(연계 피해 등) 여부. [가안: 없음] → O-45

### 2-4. 수련 횟수가 오르는 조건 [확정]

| 상황 | 수련 횟수 |
|---|---|
| 초식이 대상에게 정상적으로 발동함 (단일 수련 / 연속초식 모두) | +1 × 수련 배율 |
| 공격 대상이 없어 취소됨 | 증가 없음 |
| 내공 부족, 재사용 대기 등으로 발동하지 않음 | 증가 없음 |
| 기본 공격 | 증가 없음 |

- 수련 배율은 데이터 값이다. 기본 1.0이며, 수련 가속 효과 등 다른 배율도 같은 구조로 곱한다(확정 사항 2). 보조 무공 배율(0.5)은 보조 초식 발동을 없애면서 삭제했다(확정 사항 20).
- 배율이 소수일 때 남는 값은 소수점 누적값으로 저장해 손실 없이 합산한다. ([10-save-data.md](10-save-data.md))

- **정상 발동 판정 [확정]**: 초식이 발동하면 빗나가도(회피당해도) 수련 1회로 센다. 대상이 없어 발동하지 않으면 세지 않는다(확정 사항 28).

## 3. 내공 [확정 + 가안]

- 체력과 함께 **내공**을 가지며, 초식 발동 시 내공을 소모한다.
- 내공 최대치, 자연 회복량, 초식별 소모량은 [가안]이며 데이터로 관리한다.

## 4. 피해 계산 [가안]

초식 데이터의 공격력 계수, 캐릭터 능력치, 장비/무공 시너지를 조합한다. 아래는 구조 설명용 가안이며 수식과 계수는 밸런스 단계에서 확정한다.

```
최종 피해 = 공격력 × 초식 공격력 계수 × (1 + 피해 증가 합계) × 치명타 배율(발생 시) × 방어 보정
방어 보정 = 100 / (100 + 대상 방어력)    ← [가안]
```

초식별로 관리하는 데이터 [확정]: 공격력 계수, 공격 범위, 공격 대상 수, 내공 소모량, 재사용 대기시간, 공격 속성, 상태이상, 특수 효과, 애니메이션 및 이펙트, 수련 가능 여부.

## 5. 스테이지 루프 [확정]

```
일반 몬스터 50마리 처치 → 보스 등장 → 보스 처치 → 다음 스테이지
```

- 상단 HUD에 몬스터 처치 진행도와 보스 출현까지 남은 몬스터 수를 표시한다.
- 각 지역은 여러 스테이지로 구성한다. 지역당 스테이지 수는 [미확정] O-10.

> [미확정] 캐릭터가 쓰러졌을 때의 처리(스테이지 재시작, 이전 스테이지로 후퇴, 부활 등)와 보스 처치 실패 처리(제한 시간 여부 등). → O-06

## 6. 몬스터 [확정 기본안]

| 유형 | 특징 (기본안) |
|---|---|
| 일반 근접형 | 일정 속도로 접근해 근접 공격 |
| 빠른 돌진형 | 빠르게 접근하거나 돌진 공격, 체력 낮음 |
| 원거리형 | 사거리 밖에서 투사체 공격 |
| 방어형 | 높은 방어력/체력, 느린 이동 |
| 정예 몬스터 | 일반 몬스터 강화형, 추가 보상 |
| 보스 | 50마리 처치 후 등장, 공격 예고 + 2~3개 패턴 |

- 유형별 수치(체력, 공격력, 이동 속도, 사거리)는 [가안]이며 데이터로 관리한다.
- 원거리형은 캐릭터 사거리 밖에서 공격하므로, 캐릭터의 공격 범위/대상 수와 함께 밸런스를 맞춘다.

> [미확정] 정예 몬스터의 등장 규칙(50마리 중 몇 마리, 확률 등)과 원거리형이 캐릭터 사거리 밖에 머무를 때 캐릭터가 공격할 수 있는지. → O-07

## 7. 보스 [확정 기본안]

- 보스는 플레이어 조작과 관계없이 **계속 공격**한다(확정 사항 25).
- 플레이어는 **장비와 수호령 소환으로 체력, 방어력, 공격력을 올려** 보스를 쓰러뜨린다. 보스에서 막히면 수련, 장비 강화, 소환으로 성장한 뒤 다시 도전하는 구조다.
- 보스마다 **2~3개의 패턴**으로 시작하고, 보스 전투 연출(등장, 체력바, 패턴 예고)을 넣는다.
- 공격 예고(바닥 표시 등)는 플레이어가 대응하는 장치가 아니라 보스 전투의 긴장감을 주는 **연출**로 둔다. [가안]

## 8. 상태이상과 속성 [확정 데이터 항목]

초식 데이터에 공격 속성과 상태이상을 둔다. 원문 기획의 무공 특성에서 다음 항목이 필요하다.

- 상태이상: 기절, 출혈, 독, 빙결, 화상 등
- 속성: 화염, 빙결, 번개 등 오행 속성
- 특수 효과: 체력 흡수, 반격, 회피, 피해 흡수, 연쇄 공격, 소환 등

> [미확정] 속성 상성표(오행 상생/상극 적용 여부)와 상태이상 수치. → O-08
