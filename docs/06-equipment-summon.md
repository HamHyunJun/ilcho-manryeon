# 06. 장비 및 소환 시스템

## A. 장비

### 1. 장비 부위 [확정]

무기, 투구, 갑옷, 신발, 장신구.

> [미확정] 장신구 슬롯 수(1개 / 반지·목걸이 등 2개 이상). → O-24

### 2. 장비 등급 [확정]

```
일반 → 고급 → 희귀 → 영웅 → 전설 → 신화
```

등급이 높을수록 기본 능력치와 옵션 수가 늘어난다. 등급별 옵션 수와 능력치 범위는 [가안].

| 등급 | 추가 옵션 수 [가안] |
|---|---|
| 일반 | 0 |
| 고급 | 1 |
| 희귀 | 1 |
| 영웅 | 2 |
| 전설 | 3 |
| 신화 | 3 + 고정 시너지 옵션 1 |

### 3. 시스템 범위 [확정]

| 기능 | 상태 |
|---|---|
| 6등급 | 포함 |
| 강화 | 포함 |
| 분해 | 포함 |
| 세트 효과 | 포함 |
| 무공 시너지 옵션 | 포함 (처음부터) |
| 제작 | 후속 (구조만 열어 둠) |
| 승급 | 후속 (구조만 열어 둠) |

### 4. 강화 [확정 + 가안]

- **강화석과 은냥**을 소모해 장비의 강화 수치를 올린다. [가안: 재화 배정은 경제 기본안 기준]
- 강화 단계가 오를수록 기본 능력치가 오른다.

> [미확정] 최대 강화 단계, 강화 실패 여부(확정 성공 / 확률), 실패 시 패널티. → O-25

### 5. 분해 [확정 + 가안]

- 필요 없는 장비를 분해해 **강화석**(및 은냥)을 얻는다. [가안]
- 등급과 강화 단계가 높을수록 반환량이 많다. 반환 비율은 [가안].

### 6. 세트 효과 [확정 + 미확정]

같은 세트 장비를 여러 부위 장착하면 추가 효과를 준다.

> [미확정] 세트 구성 방식(지역별 세트 / 문파별 세트 등)과 단계(2세트, 4세트 등). → O-26

### 7. 능력치와 무공 시너지 옵션 [확정: 예시]

- 매화검법 초식 피해 증가 (특정 무공 대상)
- 특정 초식 강화 (특정 초식 대상)
- 치명타 확률 증가
- 보스 피해 증가
- 내공 회복 증가
- 피해 감소
- 체력 증가

옵션은 데이터로 정의한다. 대상(`target`)은 전체, 특정 계열, 특정 무공, 특정 초식 중 하나를 지정할 수 있게 한다.

> 충돌 주의: 주력 무공은 자유롭게 바꿀 수 있으므로, 특정 무공 전용 시너지 장비는 무공을 바꾸면 가치가 떨어진다. 계열 단위 시너지(예: 검법 피해 증가)를 섞어 완화하는 것을 [제안]한다. 장점은 무공 교체 부담 감소, 단점은 무공별 개성 약화, 난이도는 낮다(옵션 데이터 추가만 필요).

### 8. 장비 획득

- 일반 스테이지 드롭 [가안], 장비 던전(MVP 이후 추가).
- MVP는 스테이지 드롭과 기본 강화만 구현한다. ([13-mvp-roadmap.md](13-mvp-roadmap.md))

> [미확정] 장비 보관함 최대 칸 수와 가득 찼을 때 처리(자동 분해 옵션 등). → O-27

## B. 소환

### 1. 소환 종류와 역할 [확정]

| 종류 | 역할 | 전투 참여 방식 |
|---|---|---|
| 무림 동료 | 패시브 | 능력치 보너스 제공 (이동 캐릭터 아님) |
| 영물 | 보조 공격 | 일정 간격으로 자동 보조 공격 |
| 수호령 | 방어/회복 | 보호막, 체력 회복 등 |

세 종류를 모두 포함하되 역할을 분리한다. 데이터 구조는 하나의 "소환체" 스키마에 `kind`(companion / spirit_beast / guardian)를 두어 공통 관리하고, 종류별 동작만 다르게 구현한다.

> [미확정] 종류별 장착 슬롯 수, 소환체 등급 체계(장비 6등급과 같은 체계를 쓸지), 성장/강화 방식. → O-28

### 2. 소환 획득 [확정]

- **확률 소환**: 소환패를 소모해 소환한다.
- **중복 시 조각 전환**: 이미 가진 소환체가 나오면 그 소환체의 조각으로 바뀐다.
- **조각으로 확정 획득**: 조각을 모으면 원하는 소환체를 확정 획득한다(조각 소모처로 성장 사용 여부는 O-28).
- 확률과 천장은 **데이터 값**으로 둔다.
- **확률형 결제는 하지 않는다**(확정 사항 6). 소환패는 게임 플레이로 얻는다.

> [미확정] 등급별 소환 확률, 천장 횟수, 조각 전환 개수, 확정 획득 필요 조각 수. → O-29
> [미확정] 소환패 수급처(일일 미션, 업적, 보스 등)와 금원보로 소환패를 살 수 있는지. 금원보로 소환패를 사면 사실상 확률형 결제가 되므로 수익화 원칙과 충돌할 수 있다. → O-30

### 3. MVP 구현 순서 [제안]

확정 사항 9에서 "MVP 구현 순서는 별도 제안"으로 남겼다. MVP 범위(확정 사항 18)에는 소환이 포함되지 않으므로, MVP 이후 구현 순서를 제안한다.

| 순서 | 종류 | 이유 | 장점 | 단점 | 개발 난이도 |
|---|---|---|---|---|---|
| 1 | 무림 동료 | 패시브 능력치라 전투 로직 변경 없음 | 소환/조각/확률 공통 구조를 가장 가볍게 검증 | 전투 화면에서 존재감이 약함 | 낮음 |
| 2 | 수호령 | 방어/회복은 보스 패턴 대응과 연결 | 생존력 보완으로 진행 체감 | 방어/회복 수동 버튼과 역할 겹침 조정 필요 | 중간 |
| 3 | 영물 | 보조 공격은 이펙트/타격 판정 필요 | 화면 연출이 풍부해짐 | 영수문 무공과의 관계 정리 필요(O-14) | 중간 |

이 순서는 승인 전 제안이며, 다른 순서도 구조상 문제없다.
