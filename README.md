# 일초만련(一招萬鍊)

> **"수많은 무공을 수집하되, 하나의 초식을 만 번 갈고닦아 누구도 따라올 수 없는 경지에 도달한다."**

2D 픽셀 무협 세로형 Android 싱글 RPG입니다. 다양한 문파의 무공을 비급 조각으로 수집하고, 무공마다 독립적으로 보존되는 초식 수련 기록을 10,000회까지 쌓아 대성에 이르는 것이 핵심입니다.

| 항목 | 내용 |
|---|---|
| 장르 | 2D 픽셀 무협 RPG (자동 전투 + 연속초식 전환) |
| 플랫폼 | Android (세로형), Google Play 출시 목표 |
| 엔진 | Godot 4 |
| 서버 | 없음 (로컬 저장, 이중 저장 + 내보내기/가져오기) |
| 수익화 | 무료 + 광고 + 소액 인앱 결제 (편의 중심, 확률형 뽑기 결제 없음) |
| 언어 | 한국어 |

## 현재 상태

**기획 단계**입니다. 최종 기획서 v1.0이 승인 대기 중이며, 승인 전에는 본격적인 구현을 시작하지 않습니다.
